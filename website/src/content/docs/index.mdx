## The problem

Modern coding agents handle single tasks well. Real work usually needs
orchestration: fetch data, summarize it, branch on a condition, retry until
tests pass, or pause for human approval.

Graph-based systems express that cleanly, but raw DOT is verbose and hard to
type on mobile. SFN keeps the same workflow ideas in a much smaller syntax.

## SFN in three lines

```text
1. tool:curl -s https://example.com => page
2. llm "summarize {page}" => summary
3. tool:save_note --text={summary}
```

That short flow still covers the full pipeline:

- Step 1 runs a tool and names its output `page`.
- Step 2 uses that output in an LLM prompt and names the result `summary`.
- Step 3 passes the result to another tool.

## What you can express

- Linear flows with implied sequential execution
- Parallel steps using `after 0`
- Branching with `if ...`
- AND-joins with `after 1, 2`
- Human approval gates with `wait_human`
- Retry loops and iterative cycles with `goto`
